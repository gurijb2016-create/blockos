Contributing to BlockOS

Thank you for your interest in contributing to BlockOS!

How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Follow the coding style used in the project.
4. Test your changes before submitting.
5. Open a Pull Request with a clear description.

Code Guidelines

- Write clean and readable code.
- Add comments where necessary.
- Do not copy code from other operating systems without checking licenses.
- Keep commits focused on a single change.

Bug Reports

When reporting a bug, please include:

- BlockOS version
- Hardware or emulator used
- Steps to reproduce the issue
- Expected behavior
- Actual behavior

Feature Requests

Feature suggestions are welcome. Please explain:

- What the feature does
- Why it would be useful
- Possible implementation ideas

Community Rules

- Be respectful.
- No spam.
- No harassment.
- Work together to improve BlockOS.

Thank you for helping build BlockOS!
